# ASLEAN · 精益方式

> 以精益思想为核心，探索并分享精益相关的思维方式与实践方法。

ASLEAN（精益方式）是一个专注于**精益思想**与**精益思维**的开源组织。我们相信，精益不仅是一套工具或流程，更是一种看待世界、解决问题的方式。在这里，我们整理、翻译、创作与精益相关的思维模型、实践案例和学习资源，帮助个人与团队以更少的浪费创造更大的价值。

---

## 🧠 精益思维

精益思维的核心在于**消除浪费、持续改善、尊重人**。我们关注：

- **价值定义**：从客户视角出发，识别真正的价值所在
- **价值流分析**：看清从想法到交付的完整流动，找出阻塞与浪费
- **流动与拉动**：让价值连续流动，按需拉动而非推动
- **持续改善（Kaizen）**：小步快跑，日拱一卒，追求每天进步一点点
- **尊重人**：精益的根本在于激发每个人的智慧与主动性

## 🛠️ 精益实践

我们收集和整理精益方法在不同场景下的落地实践：

- **精益软件开发**：看板、限制在制品、反馈循环、持续交付
- **精益创业**：最小可行产品（MVP）、构建-测量-学习循环、验证性学习
- **精益生产**：5S、准时化（JIT）、自働化、标准作业
- **精益个人成长**：个人看板、时间价值流、习惯改善
